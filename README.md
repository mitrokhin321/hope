# HOPE Research Center

A responsive frontend landing page for HOPE Research Center, built with React
and Vite. Research categories and highlight entries are editable demonstration
content; they do not represent verified institutional activities or results.

## Development

```sh
npm install
npm run dev
```

Create a `.env` file with `VITE_API_BASE_URL` to configure the base URL for a
future API integration. The current frontend does not make API requests, and
the contact form is a non-sending demonstration.

## Quality checks

```sh
npm run lint
npm run build
```
